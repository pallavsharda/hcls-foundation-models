# Med-PaLM 2

Description: PaLM-2 model tuned for medical question answering; successor to Med-PaLM. Weights closed.

## Version note 2026-11-06

Merged Med-PaLM (original 2022 model, previously its own flagship row) into this row as its successor. Its description was: "Google's medical large language model for question answering and clinical reasoning" (source: https://arxiv.org/abs/2212.13138).

## Version note 2026-11-06

Merged MedLM into this row. MedLM is the Google Cloud product name for models built on Med-PaLM 2 (https://cloud.google.com/blog/topics/healthcare-life-sciences/introducing-medlm-for-the-healthcare-industry). Its description was: "Google's productized medical language model offering, sitting closer to medical question-answering than EHR-only pretraining." (source: https://cloud.google.com/blog/topics/healthcare-life-sciences/introducing-medlm-for-the-healthcare-industry).
